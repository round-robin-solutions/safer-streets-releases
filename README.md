# Safer Streets for Android

Preview builds of the Safer Streets app for Rotaract District 3011. This repository holds only the signed Android installers; the source code is private.

**[Download the latest APK](https://github.com/round-robin-solutions/safer-streets-releases/releases/latest/download/safer-streets.apk)**

## Installing

1. Open the link above on your Android phone.
2. When the download finishes, open it. If Android asks, allow your browser to "Install unknown apps".
3. Google Play Protect may warn that the app is from an unknown developer. Choose "Install anyway".

Each release lists its SHA-256 checksum, so you can confirm the file is the one we built. Every build is signed with the same Round Robin key, so newer versions install over older ones.

These are preview builds that talk to the test server.
